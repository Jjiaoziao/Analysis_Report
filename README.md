# Analysis_Report · 研报速览

按日期归档的每日券商研报与投研纪要知识库。采用 Apple 极简视觉与卡片交互风格，支持期数快速切换、AI 纪要深度阅读（含章节目录与对比表格渲染）、按行业与机构筛选研报原文及在线分栏阅读与下载。

在线地址（GitHub Pages）：`https://jjiaoziao.github.io/Analysis_Report/`

## 核心特性

- **毛玻璃全局导航 + ChapterNav 期数横栏**：顶部直觉切换近期研报期数，点击「全部期数」可按日期或星期模糊检索历史归档。
- **今日纪要 Bento 卡片与 Sheet 深度阅读器**：
  - 自动提炼多段纪要核心标题，支持按主题分类（每日纪要 / 市场复盘 / 投资策略 / 科技前沿等）与全站即时搜索；
  - 居中圆角阅读面板支持左侧自动目录定位、Markdown 对比表格渲染、字号缩放、全文复制以及键盘 `←` / `→` 上下篇连续翻阅。
- **全系研报原文库与分栏 PDF 工作台**：
  - 吸顶行业胶囊与发布机构筛选，一键下载 PDF 或打开在线分栏阅读工作台，同行业及当前筛选列表研报无缝切换。
- **双重自动化更新**：
  - **GitHub Actions 云端自动构建**：推送新日期 PDF 文件夹与 `.txt` 总结后自动生成 `data/dates/<日期>.json` 与 `data/index.json`；
  - **前端原生直读兜底**：即使尚未运行构建脚本，前端亦可直接解析仓库原始 `.txt` 与目录结构。

## 新增一期研报

1. 在项目根目录新建日期文件夹（如 `2026-11-26/`），放入当日 PDF 研报；
2. 将当日纪要文本放入 `data/dates/2026-11-26.txt`；
3. 本地执行 `python scripts/build_data.py`（或直接 `git push` 交由 GitHub Actions 自动构建）：
   ```bash
   python scripts/build_data.py
   git add .
   git commit -m "update: 研报 2026-11-26"
   git push
   ```
