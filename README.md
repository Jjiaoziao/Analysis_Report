# Analysis_Report · 每日研报知识库

按日期归档的券商研报知识库。支持左侧栏切换日期、研报纪要全文阅读、市场复盘、研报原文在线预览与下载，手机和电脑均可访问。

在线地址（GitHub Pages）：`https://Jjiaoziao.github.io/Analysis_Report/`

## 功能

- **左侧可伸拉/折叠日期边栏**：
  - 自由拖拽：鼠标按住边栏右侧边缘可任意拉伸宽度，尺寸自动保存至本地；
  - 快捷折叠：支持一键收起（按钮或快捷键 `Ctrl + B`），阅读区瞬间拉满；
  - 期数筛选：侧边栏支持按日期/星期几模糊搜索，历史期数再多也能一秒直达；
  - 智能状态：期数条目清晰展示研报数量、纪要篇数与最新高亮标记。
- **免手动构建 · 直接上传即看（双重自动化保证）**：
  - **云端全自动构建（GitHub Actions）**：用户只需上传文件夹与文本并 `git push`，GitHub Actions 机器人全自动运行构建脚本并生成 JSON，**本地无需敲任何脚本命令**；
  - **前端原生 TXT 直读解析引擎**：浏览器端内置 JavaScript TXT 语法解析器与 GitHub 动态探测，就算没有 JSON 也能直接读取并解析原始 `.txt` 总结与 PDF 目录！
- **纪要速览**：每日 AI 整理的研报纪要 / 市场复盘，按主题分类、全文搜索、抽屉阅读（带目录与阅读进度）；
- **研报原文库**：券商研报 PDF 分栏工作台阅读，按行业/机构自动分类，同行业报告快速切片，支持原文在线预览与下载；
- **响应式与深浅主题**：完美适配桌面大屏、iPad 与手机端（移动端抽屉遮罩），支持快捷键 `/` 搜索、`Esc` 关闭、深浅主题切换。

## 发布 / 更新

网页由 GitHub Pages 自动发布：仓库 → **Settings** → **Pages** → Source 选 **Deploy from a branch** → Branch `main` / `/(root)` → Save。

### 新增一天的研报（全自动，推荐）

1. **放好文件**：
   - 在项目根目录下放置当天的 PDF 文件夹，命名为日期格式（如 `2026-11-18/`）；
   - 将当天的总结文本放置在 `data/dates/2026-11-18.txt`（或根目录 `2026-11-18.txt`）。
2. **一键构建数据**：
   ```bash
   python scripts/build_data.py
   ```
   > 脚本会自动扫描项目中的日期目录与文本，提取券商机构，生成 `data/dates/<日期>.json` 并自动将新日期更新到 `data/index.json`（最新日期自动排在最前）。
   > 若只想构建指定日期，可运行：`python scripts/build_data.py --date 2026-11-18`。
3. **提交并推送到 GitHub**：
   ```bash
   git add .
   git commit -m "update: 研报 2026-11-18"
   git push
   ```
   约 1 分钟后，GitHub Pages 网页即可看到最新的日期与研报内容。

> 说明：PDF 直接引用仓库里的日期文件夹，不重复上传副本；txt 内容已解析进 JSON，网页不直接读取它，但保留作原始存档。
